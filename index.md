# WholesaleBackup

White-label backup software for MSPs, IT pros, and resellers. Brand the clients and the Backup Ops Web Console as your own, choose your own storage, pay a published per-device rate. [wholesalebackup.com](https://wholesalebackup.com)

## Latest releases

- **2026-10-07** Web Console: Build notification emails are easier to read, with download buttons in place of raw links.
- **2026-10-06** Web Console: Fixes and improvements.
- **2026-09-24** Windows Client: Microsoft 365 mailbox backup: mail, calendars, and contacts from an Exchange Online tenant, backed up alongside files and folders on the same schedule through a read-only app registration.
- **2026-09-11** Web Console: Hardware security keys (WebAuthn, such as YubiKey) added as a third multi-factor option for console logins, beside email codes and authenticator apps.
- **2026-09-01** Windows Client: Security and stability improvements.
